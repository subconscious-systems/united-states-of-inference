# The United States of Inference: data for agents

There are so many inference providers. How do you tell them apart? A map that gives each of 50 AI inference providers the US state it is most like (not where it is based), with what makes each one different.

Source: https://subconscious-systems.github.io/united-states-of-inference/ · Made by Subconscious (https://subconscious.dev)

## How to read this

- There are 50 states and 50 providers. Each state has exactly one provider, and each provider has exactly one state.
- The match is about character, not location. A provider gets the state it is most like (its ethos, what it is known for, what it does), not the state where it is headquartered.
- The list is not ranked. States are in alphabetical order.
- Deep link to any state with https://subconscious-systems.github.io/united-states-of-inference/#<state-name>, for example https://subconscious-systems.github.io/united-states-of-inference/#texas.

## Providers in detail

### Moonshot AI (Alabama)

Huntsville engineers designed the Saturn V that carried Americans to the moon, which makes Rocket City the obvious home for a lab named after the trip.

Beijing lab behind Kimi and the open-weight Kimi K models.

- Kimi K3 is an open-weight ~2.8T-param MoE, among the largest open models you can download
- 1M-token context, aimed at long documents and agent work
- Kimi models are a common pick for agentic coding on other hosts too

Website: https://www.moonshot.ai

On the map: https://subconscious-systems.github.io/united-states-of-inference/#alabama

Alaska is oil rigs and off-grid cabins at the end of the road, and Crusoe got its start running GPUs on gas that oil wells used to burn off.

Vertically integrated AI cloud, from energy to managed inference.

- Owns the whole stack: power generation, data centers, GPUs and the inference API
- Builds next to stranded and renewable energy, including the 1.2 GW Abilene Stargate campus
- Managed Inference sits on capacity it controls end to end, not rented GPUs

Website: https://www.crusoe.ai

On the map: https://subconscious-systems.github.io/united-states-of-inference/#alaska
